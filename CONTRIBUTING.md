# Contributing

Run `npm ci` and `npm test` before submitting a change. To try it in VS Code, open this folder and press **F5**. The Extension Development Host opens with the local build.

For a board change, try both click-to-move and drag-to-move in a narrow sidebar. For a puzzle change, check that opening and closing puzzles preserves the game in progress.

Use the issue forms for bug reports and feature ideas. A move sequence or puzzle ID is helpful for board bugs.
